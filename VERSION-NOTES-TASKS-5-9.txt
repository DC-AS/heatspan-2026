LIVE GOOGLE REVIEWS SETUP
The review module is wired to /api/google-reviews.js. To activate live Google data in Vercel, add this Environment Variable:
GOOGLE_PLACES_API_KEY = your Google Maps Platform API key with Places API (New) enabled.

Google's Places review response is limited to a small current sample. The website filters that returned sample so only 5-star reviews are displayed. If the API key is not configured, the panel fails gracefully and provides a link to Heatspan's Google reviews.

No Heatspan live-domain DNS changes are included.
